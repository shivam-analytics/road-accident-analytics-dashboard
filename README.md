# 📌 About This Project

The **Road Accident Analytics Dashboard** is a Data Analytics project built to analyze road accident data and convert raw records into meaningful visual insights.

The project contains **20,000 accident records** and focuses on understanding:

- 📍 Accident locations
- ⚠️ Accident severity
- 🔍 Accident causes
- 🕐 Accident timing
- 🌦️ Weather conditions
- 🚦 Traffic density
- 🛣️ Road types
- 👥 Casualties
- 🚘 Vehicles involved
- 📈 Risk scores

The data was cleaned using **Python and Pandas** and the final analysis was presented through an interactive **Power BI Dashboard**.
